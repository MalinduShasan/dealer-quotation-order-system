# Code of Conduct

## Our Standard

This project aims to maintain a professional, respectful, and constructive environment.

Expected behavior:

- communicate respectfully
- give clear and useful feedback
- focus on improving the product
- assume good intent
- document concerns with evidence

Unacceptable behavior:

- harassment
- insults
- hostile or dismissive communication
- intentionally harmful changes

## Enforcement

Project maintainers may moderate contributions or discussions that undermine a safe and productive collaboration environment.
